# A 股行情分析

这是一个 A 股行情分析页面，支持输入中国 A 股代码查询公开行情数据，并展示：

- 最新收盘价
- 日内高低点
- 涨跌幅
- 成交量
- 常用股票快捷查询
- 本地收藏股票
- 最近 60 个交易日 K 线图
- 最近 60 个交易日成交量图
- 最近 10 个交易日数据表格

## 项目结构

```text
.
├── index.html              首页
├── styles.css              页面样式
├── script.js               股票查询、数据处理和图表绘制逻辑
└── assets/
    └── uploads/            预留目录
```

## 技术方案

- 前端：原生 HTML、CSS、JavaScript
- 图表：Canvas 原生绘制
- 数据源：腾讯证券公开 A 股 K 线接口
- 部署方式：GitHub Pages

当前版本不依赖后端服务，适合直接托管到静态站点平台。

## 使用方式

### 1. 查询股票

打开首页后，可以通过以下方式查询：

- 输入 6 位 A 股代码后点击“查询行情”
- 点击“快捷查询”中的常用股票按钮
- 点击“我的收藏”中的股票代码

系统会根据代码自动识别沪市或深市，例如 `600519` 会请求沪市数据，`000001` 会请求深市数据。

### 2. 收藏股票

输入股票代码后点击“收藏当前”，即可将代码保存到浏览器本地收藏列表。收藏项支持点击查询和删除。

### 3. 查看结果

页面会展示：

- 查询状态
- 最新收盘价
- 涨跌幅
- 最高价和最低价
- 成交量
- K 线图
- 成交量柱状图
- 最近 10 个交易日表格

## 数据来源说明

当前实现使用的是腾讯证券公开 A 股 K 线接口：

```text
https://web.ifzq.gtimg.cn/appstock/app/fqkline/get
```

主要参数：

- `param=sh600519,day,,,60,qfq` 表示查询沪市 600519 最近 60 条前复权日 K 数据
- `sh` 表示沪市，`sz` 表示深市
- `day` 表示日线数据

## 本地开发

可以直接打开 `index.html` 查看页面结构，但建议通过静态文件服务进行预览，以避免部分浏览器环境下的限制。

## GitHub Pages 部署

### 1. 提交并推送仓库

将项目推送到 GitHub 仓库。

### 2. 开启 Pages

在仓库设置中选择：

```text
Settings -> Pages -> Deploy from branch
```

部署分支建议选择：

```text
main / root
```

### 3. 访问地址

部署成功后，可以通过以下形式访问：

```text
https://你的用户名.github.io/
```

或者：

```text
https://你的用户名.github.io/仓库名/
```

## 限制说明

- 这是纯前端实现，数据直接在浏览器端请求公开接口
- 腾讯证券公开接口可能存在访问频率、CORS 或接口变更限制
- 部分市场或代码可能不在该接口支持范围内
- 如果后续需要更稳定的数据源、更多指标或更高请求频率，建议增加后端中转层
